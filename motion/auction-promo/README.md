# Аукцион квартиры · Циан

Ролик о фиче, собран скиллом product-motion.

- Статус: версия 2 — все сценарии, пояснения слева, точная привязка курсора.
- Формат: 15 секунд, 1920×1080, 24 кадра/с, без звука, H.264 MP4 не больше 20 МБ.
- Результат: `out/auction-promo_all-scenarios.mp4`.
- MP4 и содержимое `build/`/`out/` хранятся локально, в Git не включаются; видео загружается на платформу отдельно.
- Сцены: реальные DOM и CSS локального `/auction`, сохранённые в `assets/`.
- Бренд-профиль: `brand/` (снимок на момент создания: ../brand).

## Бриф

Фича: аукцион квартиры. Назначение: короткое промо всех сценариев.
Аудитория: покупатели и продавцы квартир. Язык интерфейса: русский.
Слева постоянно виден список из пяти сценариев с краткими описаниями;
текущий сценарий выделяется. Справа показывается соответствующий реальный экран.

| Время | Сценарий | Реальные состояния |
| --- | --- | --- |
| 0–4,25 с | Продавец публикует аукцион | Настройка → проверка условий → опубликован |
| 4,25–8,65 с | Покупатель смотрит квартиру и делает ставку | Фото → ставка → проверка → лидерство; управление уведомлением |
| 8,65–10,8 с | Проверка минимальной суммы | Низкая сумма → сообщение с допустимым минимумом |
| 10,8–13 с | Повтор после ошибки | Ошибка отправки → повтор → проверка → успех |
| 13–15 с | Завершение | Финальная цена и инструкции победителю |

Тексты интерфейса и данные не придуманы. Пояснения слева — редакционные
описания поведения из `src/pages/AuctionPage.tsx`. Технический блок
«Проверить состояния прототипа» скрыт. При монтаже камера приближает
нужную область реального экрана. Координаты курсора берутся из фактических
DOM-кнопок после масштабирования, а не из заданных вручную точек.

## Пересборка

Команды выполняются из корня репозитория. Для обновления снимков нужен
локальный прототип на `http://127.0.0.1:4173/auction` (`npm run dev -- --port 4173`).

```sh
.venv-motion/bin/python motion/auction-promo/capture.py
.venv-motion/bin/python motion/auction-promo/check_cursor.py
.venv-motion/bin/python .agents/skills/product-motion/scripts/verify_scene.py motion/auction-promo/video.html --fmt h
.venv-motion/bin/python .agents/skills/product-motion/scripts/render.py motion/auction-promo/video.html video --fmt h --out motion/auction-promo/build/all-scenarios-render.mp4
ffmpeg -i motion/auction-promo/build/all-scenarios-render.mp4 -map 0:v:0 -an -c:v copy -movflags +faststart motion/auction-promo/out/auction-promo_all-scenarios.mp4
.venv-motion/bin/python .agents/skills/product-motion/scripts/verify_media.py motion/auction-promo/plan.js motion/auction-promo/out/auction-promo_all-scenarios.mp4 --sheet
```

Превью с ползунком: `video.html?preview=1` (через локальный сервер).
Временные файлы и отчёты — в `build/`, результаты — в `out/`.
Chromium может требовать запуска вне macOS-песочницы.

Проверено: девять основных экранов, восемь попаданий курсора в реальные
контролы, детерминизм кадров, загрузка шрифта, неподвижный финал,
параметры MP4 и полное декодирование. Первая версия сохранена отдельно
как `out/auction-promo_16x9.mp4`.
